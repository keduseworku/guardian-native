# Grilling

Map the unresolved design decisions and their dependencies. Read the repository to
settle facts; use existing requests, specs and accepted decisions to settle intent.
Ask the user only about material ambiguity, competing outcomes or a consequential
choice not already authorized. Give a concrete recommendation with each question.
Ask dependent questions after their prerequisites are settled; keep each round small.
Routine implementation choices belong to the supervising agent. Continue independent
work while waiting. Stop when the behavior, interfaces, non-goals and observable
acceptance are clear enough to implement the agreed slice. An already clear task
does not need another interview. Record important decisions for reuse.
