# Grill with docs

For project inception or materially ambiguous design, read [grilling](../grilling/METHOD.md)
and [domain-modeling](../domain-modeling/METHOD.md). Resolve terminology and consequential
decisions using the repository first. Record resolved terms and non-obvious, costly
decisions in the existing project planning space. Reuse those decisions on ordinary work.
