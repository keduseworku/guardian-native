# Configure the selected methods once per repository

Inspect the existing AGENTS instructions, domain guides, glossary/ADRs, project issue
workflow, accepted code, Python environment and configured checks. Preserve team
conventions and existing user choices. Discover the team's actual interpreter, environment,
lint/type/test commands and authoritative examples from its existing configuration.

Keep the product outcome, milestone and current task in a small specification.
Reuse an existing team tracker only through its authorized workflow. Record its actual
location and domain references; do not create a separate planning repository or database.
Reuse root/local AGENTS maps. Create glossary/ADR documents only for a resolved term
or consequential, non-obvious decision. A normal fix does not need scaffolding.

Inspect the curated manifest and existing domain skills. Resolve naming conflicts
once, retaining team-specific instructions. The selective routes live in WORKFLOW.md;
only the selected methods are read for daily work. Keep the complete Ponytail resource
available. Confirm only material choices that inspection and prior authorization
cannot settle. Record setup in the planning spec; repeat only when that setup changes.
